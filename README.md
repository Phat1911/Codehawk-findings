# Smart Contract Security Findings

This directory contains my smart contract security learning write-ups from CodeHawks challenges.

These are educational security reviews focused on my analysis, findings, explanations, and minimal PoCs where applicable. The original challenge source code belongs to its authors and project maintainers.

Some challenges may be historical or beginner-level. Findings may be independently discovered, independently discovered with solution verification, or solution-assisted learning. I will disclose the analysis type for each challenge or finding.

This directory should not be interpreted as a professional audit of a production protocol.
